# Trippi

All-in-one trip planner and budget tracker.

## Live site (GitHub Pages)
- Website: `https://arnolda2.github.io/Trippi2/` (auto-deployed from `web/`)

## Run the app (Expo Go)
1. Install prerequisites: Node 18+, npm 9+, Expo Go on your phone
2. In a terminal:
```bash
cd mobile
npm install
npm start
```
3. Scan the QR code with Expo Go.

More details in `DEVELOPMENT_SETUP.md`. File layout in `docs/FILE_STRUCTURE.md`.

### Local preview
You can open `web/index.html` directly in a browser, or run a quick local server:
```bash
cd web
python3 -m http.server 5173
# open http://localhost:5173
```
