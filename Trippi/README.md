# Trippi

All-in-one trip planner and budget tracker.

## Run the app (Expo Go)
1. Install prerequisites: Node 18+, npm 9+, Expo Go on your phone
2. In a terminal:
```bash
cd mobile
npm install
npm start
```
3. Scan the QR code with Expo Go.

More details in `DEVELOPMENT_SETUP.md`. File layout in `docs/FILE_STRUCTURE.md`.
