# RoommateSwipe - Project Documentation

## Project Overview

RoommateSwipe is a mobile application designed to help users find compatible roommates and housing options. Inspired by dating apps like Tinder, it implements a swipe interface for browsing potential roommates, along with features for viewing matches, chatting, and managing user profiles. The app supports two main user types: those who have a room to offer and those looking for a room to rent.

## Detailed File Descriptions

### Models

#### 1. Profile.swift
- **Purpose**: Defines the comprehensive data model for all user profiles in the application.
- **Key Components**: 
  - `Profile` struct (conforms to `Identifiable`)
  - Fields for basic info (name, age, gender), property details, location data, lifestyle preferences
  - Enum for profile types (offering room, seeking room, both, apartment company)
- **Contribution**: Serves as the foundation for representing other users in the app, especially during swiping and matching.

#### 2. UserProfile.swift
- **Purpose**: Represents the current logged-in user's profile information.
- **Key Components**:
  - `UserProfile` struct with personal data fields
  - Simplified version of Profile with additional fields specific to the current user
  - Default initialization with empty values
- **Contribution**: Stores and manages the current user's information throughout the app, especially in profile viewing and editing.

### ViewModels

#### 3. RoommateViewModel.swift
- **Purpose**: Central data management and business logic for the application.
- **Key Components**:
  - `RoommateViewModel` class (conforms to `ObservableObject`)
  - Sample profile data
  - Current user's profile data
  - Methods for filtering, matching, and managing profile interactions
- **Contribution**: Serves as the app's state management system, connecting views with data and handling user interactions.

## Application Flow

1. **Startup**: RoommateSwipeApp initializes the environment and loads ContentView.
2. **Authentication**: ContentView displays LoginView for unauthenticated users.
3. **Registration**: New users select their profile type and complete the multi-step registration.
4. **Main Interface**: Authenticated users access the app through RootTabView's navigation tabs:
   - **Swipe**: Browse potential roommates with SwipeView
   - **Map**: Explore properties geographically with MapView
   - **Liked**: View profiles the user has liked
   - **Matches**: Access mutual matches and chat
   - **Profile**: View and edit personal profile

4. **Property Map**  
   - A built-in map shows property locations for users offering a room.
   - Each property pin can be tapped to see details such as rent, amenities, and pictures.

5. **Profile Editing**  
   - Users can edit their own profile, update property images, or adjust search filters at any time.

6. **Filtering & Preferences**  
   - City, gender, budget, and other preferences can be set so that only relevant profiles appear in the swipe deck.

7. **General Flow**  
   - Upon launching, the user sees a loading screen, then either logs in or signs up.
   - Once authenticated, they navigate via a tab bar to swipe, view the map, see liked profiles, check matches, or edit their profile.

Overall, the project provides a complete SwiftUI-based iOS application for discovering and matching with potential roommates, handling profile creation, property details, and real-time matching logic.

import SwiftUI
import SwiftData

struct ContentView: View {
    // MARK: - SwiftData environment
    @Environment(\.modelContext) private var modelContext
    @Query private var items: [Item]
    
    // MARK: - Loading State
    @State private var isLoading: Bool = true
    @State private var isAuthenticated: Bool = false
    
    // MARK: - ViewModel
    @StateObject var viewModel = RoommateViewModel()
    
    var body: some View {
        ZStack {
            if isLoading {
                LoadingView()
                    .transition(.opacity)
            } else if !isAuthenticated {
                LoginView(isAuthenticated: $isAuthenticated)
                    .transition(.opacity)
            } else {
                // The main UI with tabs
                RootTabView()
                    .environmentObject(viewModel)
                    .transition(.opacity)
            }
        }
        .onAppear {
            // Simulate a 2-second loading time
            DispatchQueue.main.asyncAfter(deadline: .now() + 2) {
                withAnimation {
                    isLoading = false
                }
            }
        }
    }
    
    // You can keep or remove the default SwiftData logic below:

        }
    }

        withAnimation {
            for index in offsets {
                modelContext.delete(items[index])
            }
        }
    }
    */
}

import SwiftUI
import MapKit

struct Profile: Identifiable {
    let id = UUID()
    
    // Basic Info
    let name: String
    let age: Int
    let gender: String
    let city: String
    let bio: String
    
    // Profile Images
    let imageName: String
    let propertyImageName: String?
    
    // Living Situation
    let hasRoom: Bool
    let needsRoom: Bool
    let moveInDate: Date
    
    // Location & Budget
    let preferredNeighborhoods: [String]
    let budgetRange: ClosedRange<Double>
    let coordinate: CLLocationCoordinate2D
    
    // Property Details (if hasRoom is true)
    let numberOfRooms: Int
    let numberOfBathrooms: Int
    let amenities: String
    let rent: String
    let address: String
    
    // Lifestyle Preferences
    let cleanliness: Int // 1-5 scale
    let partying: Int // 1-5 scale
    let smoking: Bool
    let pets: Bool
    let petTypes: [String]?
    let wakeUpTime: String
    let sleepTime: String
    
    // Additional Info
    let habits: String
    let lookingFor: String
    let verificationStatus: Bool
    let isBlocked: Bool
    
    // Computed property for profile type
    var profileType: ProfileType {
        if hasRoom && needsRoom {
            return .both
        } else if hasRoom {
            return .offering
        } else if needsRoom {
            return .seeking
        } else {
            return .apartmentCompany
        }
    }
}

enum ProfileType {
    case offering
    case seeking
    case both
    case apartmentCompany
}

                return false
            }
            
            // Filter by budget

                return false
            }
            
            // Filter by move-in date
            if profile.moveInDate > filterMoveInDate {
                return false
            }

struct ChatView: View {
    let profile: Profile
    @Environment(\.dismiss) private var dismiss
    @State private var messageText = ""
    @State private var messages: [ChatMessage] = []
    
    var body: some View {
        NavigationView {
            VStack {
                // Chat messages
                ScrollView {
                    LazyVStack(spacing: 12) {
                        ForEach(messages) { message in
                            ChatBubble(message: message)
                                .padding(.horizontal)
                        }
                    }
                    .padding(.top)
                }
                
                // Message input
                HStack {
                    TextField("Type a message...", text: $messageText)
                        .textFieldStyle(RoundedBorderTextFieldStyle())
                        .padding(.horizontal)
                    
                    Button {
                        sendMessage()
                    } label: {
                        Image(systemName: "paperplane.fill")
                            .foregroundColor(.blue)
                    }
                    .padding(.trailing)
                    .disabled(messageText.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty)
                }
                .padding(.vertical, 8)
                .background(.thinMaterial)
            }
            .navigationTitle("Chat with \(profile.name)")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .navigationBarLeading) {
                    Button("Back") {
                        dismiss()
                    }
                }
            }
        }
    }
    
    private func sendMessage() {
        let trimmedText = messageText.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !trimmedText.isEmpty else { return }
        
        let newMessage = ChatMessage(
            id: UUID(),
            text: trimmedText,
            isFromCurrentUser: true,
            timestamp: Date()
        )
        messages.append(newMessage)
        messageText = ""
        
        // Simulate a response after a short delay
        DispatchQueue.main.asyncAfter(deadline: .now() + 1.5) {
            let response = ChatMessage(
                id: UUID(),
                text: "Thanks for your message! I'll get back to you soon.",
                isFromCurrentUser: false,
                timestamp: Date()
            )
            messages.append(response)
        }
    }
}

struct ChatBubble: View {
    let message: ChatMessage
    
    var body: some View {
        HStack {
            if message.isFromCurrentUser { Spacer() }
            
            Text(message.text)
                .padding(12)
                .background(message.isFromCurrentUser ? Color.blue : Color.gray.opacity(0.2))
                .foregroundColor(message.isFromCurrentUser ? .white : .primary)
                .cornerRadius(16)
            
            if !message.isFromCurrentUser { Spacer() }
        }
    }
}

struct ChatMessage: Identifiable {
    let id: UUID
    let text: String
    let isFromCurrentUser: Bool
    let timestamp: Date
}

import SwiftUI
import MapKit

struct SwipeCardView: View {
    let profile: Profile
    
    // Callbacks triggered by swiping
    let onSwipeLeft: () -> Void
    let onSwipeRight: () -> Void
    
    // For the property detail sheet
    @State private var showPropertySheet = false
    
    // For the profile detail sheet
    @State private var showDetail = false
    
    // Tracks the drag offset
    @State private var translation: CGSize = .zero
    private let swipeThreshold: CGFloat = 100

    var body: some View {
        GeometryReader { geo in
            // ZStack that is fully swipable
            ZStack(alignment: .topTrailing) {
                
                // MAIN BACKGROUND: user's image + gradient
                Image(profile.imageName)
                    .resizable()
                    .scaledToFill()
                    .frame(width: geo.size.width, height: geo.size.height)
                    .clipped()
                
                LinearGradient(
                    gradient: Gradient(colors: [Color.clear, Color.black.opacity(0.6)]),
                    startPoint: .center,
                    endPoint: .bottom
                )
                .frame(width: geo.size.width, height: geo.size.height)
                
                // PROPERTY THUMBNAIL
                VStack {
                    HStack {
                        Spacer()
                        if let propertyImageName = profile.propertyImageName {
                            Image(propertyImageName)
                                .resizable()
                                .scaledToFill()
                                .frame(width: 150, height: 100)
                                .clipped()
                                .cornerRadius(8)
                                .onTapGesture {
                                    showPropertySheet = true
                                }
                                .padding(.top, 10)
                                .padding(.trailing, 10)
                        }
                    }
                    Spacer()
                }
                
                // NAME, AGE, LOCATION, "MORE INFO" near bottom
                VStack(alignment: .leading, spacing: 6) {
                    Text("\(profile.name), \(profile.age)")
                        .font(.title)
                        .fontWeight(.bold)
                        .foregroundColor(.white)
                    
                    Text(profile.city)
                        .font(.headline)
                        .foregroundColor(.white)
                    
                    Button(action: {
                        showDetail = true
                    }) {
                        Text("More Info")
                            .fontWeight(.semibold)
                            .padding(.vertical, 6)
                            .padding(.horizontal, 12)
                            .background(Color.white.opacity(0.8))
                            .cornerRadius(8)
                    }
                }
                .padding(.horizontal, 16)
                .padding(.bottom, 80)
                .frame(maxWidth: .infinity, alignment: .leading)
                .padding(.top, geo.size.height * 0.65)
                
            }
            .contentShape(Rectangle()) // entire ZStack is swipable
            // Apply translation & rotation to the entire ZStack
            .offset(x: translation.width, y: translation.height)
            .rotationEffect(.degrees(Double(translation.width / geo.size.width) * 25), anchor: .bottom)
            .animation(.interactiveSpring(), value: translation)
            .gesture(
                DragGesture()
                    .onChanged { value in
                        withAnimation(.interactiveSpring()) {
                            translation = value.translation
                        }
                    }
                    .onEnded { value in
                        handleSwipeEnd(value: value, geo: geo)
                    }
            )
            // SHEET for the user's detailed profile
            .sheet(isPresented: $showDetail) {
                DetailedProfileView(
                    profile: profile,
                    onLike: { onSwipeRight() },
                    onDislike: { onSwipeLeft() }
                )
            }
            // SHEET for the property details
            .sheet(isPresented: $showPropertySheet) {
                DetailedPropertyView(profile: profile)
            }
        }
    }
    
    private func handleSwipeEnd(value: DragGesture.Value, geo: GeometryProxy) {
        if value.translation.width > swipeThreshold {
            // Swipe Right
            withAnimation(.interactiveSpring()) {
                translation = CGSize(width: geo.size.width * 1.5, height: value.translation.height)
            }
            DispatchQueue.main.asyncAfter(deadline: .now() + 0.2) {
                onSwipeRight()
            }
        } else if value.translation.width < -swipeThreshold {
            // Swipe Left
            withAnimation(.interactiveSpring()) {
                translation = CGSize(width: -geo.size.width * 1.5, height: value.translation.height)
            }
            DispatchQueue.main.asyncAfter(deadline: .now() + 0.2) {
                onSwipeLeft()
            }
        } else {
            // Snap back
            withAnimation(.interactiveSpring()) {
                translation = .zero
            }
        }
    }
}

import SwiftUI

struct SwipeView: View {
    @EnvironmentObject var viewModel: RoommateViewModel
    
    @State private var tempCityFilter: String = ""
    @State private var tempGenderFilter: String = "No Preference"
    
    var body: some View {
        NavigationView {
            VStack(spacing: 0) {
                if viewModel.filteredProfiles.isEmpty {
                    Spacer()
                    Text("No more profiles in your area.")
                        .font(.title2)
                        .foregroundColor(.gray)
                        .padding()
                    Spacer()
                } else {
                    GeometryReader { geo in
                        ForEach(viewModel.filteredProfiles.indices, id: \.self) { index in
                            let profile = viewModel.filteredProfiles[index]
                            
                            SwipeCardView(
                                profile: profile,
                                onSwipeLeft: {
                                    viewModel.dislike(profile: profile)
                                    viewModel.removeProfile(profile: profile)
                                },
                                onSwipeRight: {
                                    viewModel.like(profile: profile)
                                    viewModel.removeProfile(profile: profile)
                                }
                            )
                            .stacked(at: index, in: viewModel.filteredProfiles.count)
                            .frame(width: geo.size.width, height: geo.size.height - 30)
                        }
                    }
                }
            }
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .principal) {
                    filterBar
                }
            }
            .background(Color(.systemBackground))
        }
    }
    
    // The filter bar at the top
    private var filterBar: some View {
        HStack(spacing: 8) {
            // City text field
            TextField("City", text: $tempCityFilter)
                .textFieldStyle(RoundedBorderTextFieldStyle())
                .frame(width: 100)
                .font(.system(size: 14))
            
            // Gender picker
            Picker("Gender", selection: $tempGenderFilter) {
                Text("All").tag("No Preference")
                Text("M").tag("Male")
                Text("F").tag("Female")
            }
            .pickerStyle(SegmentedPickerStyle())
            .frame(width: 120)
            
            // Apply button
            Button {
                viewModel.filterCity = tempCityFilter
                viewModel.filterGender = tempGenderFilter
            } label: {
                Text("Apply")
                    .font(.system(size: 14, weight: .medium))
                    .padding(.horizontal, 8)
                    .padding(.vertical, 4)
                    .background(Color.blue.opacity(0.2))
                    .cornerRadius(6)
            }
        }
        .padding(.horizontal, 8)
    }
}

extension View {
    func stacked(at index: Int, in total: Int) -> some View {
        let offset = Double(total - index) * 4
        return self.offset(x: 0, y: offset)
    }
}
