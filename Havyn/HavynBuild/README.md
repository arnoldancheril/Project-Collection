# Havyn

A mobile application to help users find perfect roommates in Chicago.

## About

Havyn is designed to streamline the roommate finding process through an intuitive, swipe-based interface. The app allows users to browse potential roommates, view their profiles, and connect with matches.

## Features

- User authentication (login/signup)
- Roommate browsing with swipe interface
- Map view of available roommates
- Messaging between matched users
- Detailed user profiles

## Technology Stack

- React Native with Expo
- TypeScript
- Firebase (Authentication, Firestore, Storage)
- React Navigation
