# Puzzle

This folder contains the Puzzle project.

## What is tracked in Git
- Source code, configs, and documentation

## What is intentionally not tracked
- Virtual environments (e.g. `.venv/`)
- Generated outputs (e.g. `focused_output/`)
- OS/editor artifacts (e.g. `.DS_Store`)

If you need to publish a sample output, add a small sanitized file under a new folder like `examples/` and keep large/private outputs ignored.
