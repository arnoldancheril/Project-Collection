⚠️ The Derived Line Fallacy

Understanding why previous model performance was overstated.

The Problem

Previous models calculated "betting lines" as player averages:

# Previous approach (WRONG) "Line" = L10_average × 1.05 # Simple 5% buffer

Real Example

Metric Derived Line Actual DraftKings Line
Peyton Watson - Rebounds 4.9 (L10 avg) → 5.15 adjusted 6.5
Model Projection 6.0 rebounds 6.0 rebounds
Model Pick OVER 5.15 → HIT ✅ UNDER 6.5 → HIT ✅
If Actual = 6 OVER 5.15 → HIT ✅ UNDER 6.5 → HIT ✅

Why It Matters

The model was measuring: "Can we predict if a player exceeds their average?"

But betting requires: "Can we beat the sportsbook's line?"

ℹ️
Model V10 Solution Model V10 requires actual sportsbook lines, ensuring edge calculations reflect real betting opportunities. No line = No pick.

🛡️ Defense vs Position (DVP)

How team defense ratings affect player prop predictions.

What It Measures

For each NBA team and each position (PG, SG, SF, PF, C), DVP data shows:

  • PTS Allowed Rank - How many points they allow to that position (1 = best defense)
  • REB Allowed Rank - How many rebounds they allow (1 = best)
  • AST Allowed Rank - How many assists they allow (1 = best)

Rating Thresholds

Rating Rank Range Model Adjustment
Elite 1-5 -12% projection
Good 6-10 -6% projection
Average 11-20 No adjustment
Weak 21-30 +6% projection

Data Source

DVP data is sourced from Hashtag Basketball.
