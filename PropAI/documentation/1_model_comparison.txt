================================================================================
                    THE DERIVED LINE FALLACY
================================================================================

ALL models V9+ address this critical flaw discovered in earlier versions:

PROBLEM: Previous models tested picks against derived lines (player averages)
instead of actual sportsbook lines. This inflated hit rates by 5-15%.

EXAMPLE:
  Player L10 average: 22.5 PTS
  Model "line": 22.5 × 1.05 = 23.6
  Actual DraftKings: 25.5 PTS
  Model predicts: OVER 23.6 → counts as HIT if actual = 24
  Reality: OVER 25.5 → MISS if actual = 24

SOLUTION: Track line source separately, require sportsbook lines when possible.

================================================================================
                    MODEL V9 - LINE-AWARE MODEL
================================================================================

Version: 9.0 | Created: January 2026

PERFORMANCE:
  Overall: 68.6% (59/86 picks)
  Sportsbook lines: Track separately (TRUE accuracy)
  Derived lines: Track separately (likely inflated)

KEY INNOVATION:
  First model to track line source (sportsbook vs derived)
  - Sportsbook line: Use directly
  - Derived line: Player avg × 1.05 adjustment
  - Warning system for line discrepancies

PATTERNS:
  - Cold Bounce (PREMIUM): L5 15%+ below L15, last game recovering
  - Hot Sustained (HIGH): L5 20%+ above L15, maintaining momentum

CONFIGURATION:
  use_sportsbook_lines: true
  line_adjustment_factor: 1.05
  min_edge_vs_actual_line: 5.0%
  max_picks_per_player: 1

WHY SUPERSEDED:
  - Still allowed too many derived line picks
  - Needed stricter filtering

================================================================================
            REGRESSION CONTRIBUTION MODEL (RCM)
================================================================================

Version: 1.4 | Created: January 2026

PERFORMANCE:
  Overall: 60.4% (191/316)
  PREMIUM: 87.5% (8 picks) - Exceptional on small sample
  HIGH: 59.9% (289 picks)

KEY INNOVATION:
  Models contribution RATE not raw stats
  - Contribution Rate = Player Stat / Team Stat
  - More stable than raw stats
  - Naturally adjusts for pace and game flow

METHODOLOGY:
  1. Calculate contribution rates at L5/L10/Season
  2. Blend with 35% regression to mean (Bayesian)
  3. Project team totals
  4. Apply opponent DVP adjustments

STRATEGIC DECISIONS:
  PTS UNDER only (63.9% vs 48.3% OVER)
  No AST (44.8% OVER was terrible)
  REB both ways (~59% both)

CONFIGURATION:
  min_games_required: 10
  min_edge_pct: 10.0% (OVER)
  min_edge_under: 8.0% (UNDER)
  regression_strength: 0.35

================================================================================
                    KEY LEARNINGS ACROSS ALL MODELS
================================================================================

1. SPORTSBOOK LINES MATTER
   - Derived line hit rates are 5-15% inflated
   - Always report sportsbook vs derived separately
   - TRUE accuracy = sportsbook line performance

2. PATTERN VALIDATION IS CRITICAL
   - Cold Bounce: 65-85% hit rate (BEST OVER pattern)
   - Hot Sustained: 25-55% (UNRELIABLE - disable it)
   - Elite Defense: 62-72% (STRONG UNDER signal)
   - B2B Fatigue: 56-75% (SOLID UNDER signal)

3. DIRECTION STRATEGY
   - PTS: UNDER preferred (63% vs 48% OVER)
   - REB: Both directions work (~59%)
   - AST: EXCLUDE entirely (~54% = coin flip)

4. QUALITY vs QUANTITY TRADEOFF
   - V16: 127 picks at 72.4% (BEST)
   - V19: 1,718 picks at 56.3%
   - Fewer high-confidence picks > many marginal picks

5. FACTOR COUNT SWEET SPOT
   - 3 factors optimal (74.4% hit rate)
   - Beyond 3 factors: diminishing returns
   - Single-factor picks underperform

6. DEFENSE RANKINGS
   - Elite = Top 3 (not Top 5!)
   - Top 4-5 defense only 27-40% for UNDER
   - Be strict about "elite" classification
